# Data Stories Info Viz

This repository contains data and analysis notebooks for studying information-visualisation data stories, with a focus on how projects integrate data sources, structure narrative sections, use chart and interaction features, and balance exploratory versus explanatory communication.

The dataset is built from a collection of student data-story websites and related notebooks. The analysis derives project- and chart-level indicators such as interaction level, chart type families, number of data sources, creator complexity, and exploratory/explanatory classification.

## Repository Contents

### Notebooks

- `data_affordances_analysis.ipynb` - main reproducible analysis notebook for data affordances, interaction levels, creator complexity, data-source use, and exploratory/explanatory dimensions.
- `exploration.ipynb` - exploratory analysis organized around research questions on visualisation practices, data quality, data integration, and implications for digital library design.
- `eda_vs_kd.ipynb` - analysis comparing exploratory data storytelling and knowledge-delivery patterns at project level.
- `features_interaction.ipynb` - supporting notebook for chart design and interaction feature analysis.

### Source and Processed Data

- `records.csv` - project-level catalogue with course/exam metadata, repository and website URLs, people, declared data sources, and data-integration notes.
- `website_structure.csv` - manually structured website content, including text roles, chart metadata, titles, annotations, data points, repetition, and data-source fields.
- `website_structure_with_interactions.csv` - website structure enriched with an `interaction_level` field.
- `website_structure_with_interactions_derived.csv` - website structure enriched with interaction levels and derived chart-type categories.
- `processed_dataset.csv` - consolidated dataset with derived fields such as `chart_type_derived`, `data_source_list`, and `data_source_count`.

### Derived Analysis Tables

- `chart_complexity_no_datasource_boost.csv` - chart-level creator complexity scores and chart/data-source descriptors.
- `project_complexity_no_datasource_boost.csv` - project-level creator complexity aggregates, including mean, sum, max complexity, chart counts, and data-source counts.
- `project_level_eda_kd.csv` - project-level exploratory/explanatory indicators, normalized scores, and class labels.

### Figures

The `imgs/` folder contains exported plots generated by the notebooks, including:

- chart-type usage and derived chart-family distributions
- chart-type versus data-source heatmaps and stacked charts
- creator-complexity and data-source comparisons
- interaction-level and data-source visualisations
- exploratory/explanatory project classification plots
- rule-based design-feature and narrative-role summaries

## Typical Workflow

1. Start from `records.csv` and `website_structure.csv`.
2. Use the analysis notebooks to enrich the website structure with interaction levels, derived chart types, data-source counts, and complexity metrics.
3. Review the derived CSV files for chart-level and project-level indicators.
4. Use the generated figures in `imgs/` for reporting and interpretation.

## Setup

Install the pinned Python dependencies before rerunning the notebooks:

```bash
pip install -r requirements.txt
```

The environment includes Jupyter/IPython packages and the main analysis libraries used by the notebooks, including pandas, numpy, matplotlib, seaborn, scipy, and statsmodels.

- The repository includes generated CSV outputs and figures so the analysis results can be inspected without rerunning every notebook.
